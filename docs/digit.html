My Website Development Experience

Creating websites using GitHub and PSU WordPress helped me learn more about how websites are designed and created. Using GitHub was more challenging because I had to work with code and figure out how to fix mistakes when things did not work correctly. It took more time and patience, but it helped me understand how coding works and how websites are built from scratch. Using PSU WordPress was a much easier experience because I did not have to write as much code. I could focus more on the design, layout, and content of my website. It was easier to make changes and organize my pages the way I wanted. Overall, both projects taught me different skills and helped me understand the process of creating a website. I learned that coding gives you more control over how a website works, while WordPress makes designing a website simpler and faster. One of the biggest challenges with GitHub was learning how to use HTML and CSS and understanding how to fix errors in my code. With WordPress, the biggest challenge was learning how to use the different features and making sure my pages were organized and visible. Both websites required patience and attention to detail, but WordPress was easier to learn because it had tools that made designing the website simpler. Another difference between the two methods was how I could change the layout and organization. With GitHub, I had to edit the code to change different parts of my website. This gave me more freedom, but it could also be confusing if something went wrong. With WordPress, I could make changes more easily using the built-in design tools. I think both methods have advantages, depending on how much control you want over your website and how much coding you know. To improve my websites in the future, I would like to learn more about HTML, CSS, and different design techniques. I also want to improve my ability to organize information and make websites easier for people to navigate. Learning more about coding would help me have more control over my designs, while learning more WordPress features would help me create websites more efficiently. Overall, this experience helped me develop new skills and gave me a better understanding of the different ways websites can be created.
